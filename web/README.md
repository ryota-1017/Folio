# Folio — Digital Planner

Material Design 3（Warm Neutral / Sandstone）をベースにした、PC・タブレット向けデジタル手帳アプリです。

## 主な機能
- 1〜12月の段差インデックスと月間カレンダー（月曜始まり・週番号・前後月ミニカレンダー・今日セル太枠強調）
- 日付クリックで見開き2ペインのデイリー画面（スケジュール一覧・終了時間・メモ表示、Daily Note 罫線/ドット切替）
- 大学モード切替（月〜金 × 1〜5限の時間割、出席/欠席/遅刻カウンター、課題締切管理）
- ブラウザ保存（`localStorage`）によるデータ自動保存＆PWAホーム画面追加対応
